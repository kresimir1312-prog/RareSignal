Import requirements

CSV headers must match these field names. Required fields are marked with *.

FieldRequiredExample / rule
sale_id*Stable unique transaction ID; used to detect duplicates
card_id*Exact TCGdex card ID or canonical RareSignal identity
variant_id*Exact printing / finish identity, not just the card name
language*English only in this v1 import
grade_type*RAW or PSA10
conditionRAW onlyNear Mint, Lightly Played, etc.; PSA10 must say PSA 10
sale_status*COMPLETED only
sold_at*ISO date/time, e.g. 2026-11-05T18:30:00Z
price / currency*Positive number and uppercase ISO currency, e.g. 125.50 / EUR
market / source*Region and named source, e.g. Europe / eBay
evidence_typeRecommendedDIRECT_TRANSACTION, PROVIDER_REPORTED or AGGREGATE; default PROVIDER_REPORTED
source_urlOptionalDirect transaction URL for DIRECT_TRANSACTION; provider page otherwise
is_lotOptionaltrue records are rejected; default false
notesOptionalProvenance or review notes
Do not import asking prices, bundles/lots, cancelled sales, duplicate transactions, unverified grades or mismatched variants. RAW and PSA 10 are never combined.
